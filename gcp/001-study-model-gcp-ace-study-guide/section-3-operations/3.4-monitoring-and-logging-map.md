## 2. Cloud Monitoring

```

                            │     - Login to scoping project to see all
                            │

                            │     - Conditions on metrics
                            │     - Notification channels:
                            │         email, SMS, Slack,
                            │         PagerDuty, Pub/Sub, webhook
                            │     - Auto-close window
        Cloud Monitoring ───┤
                            ├── UPTIME CHECKS
                            │     - HTTP / HTTPS / TCP
                            │     - Multi-region probes
                            │     - Latency + availability
                            │
                            └── CUSTOM METRICS
                                  - Logs-based metrics
                                      counter / distribution
                                  - OpenTelemetry / Ops Agent
```

### Logs-Based Metric

```
   Log entries          ┌─────────────┐         ┌──────────────┐
   matching filter ──►  │  Logs-based │  ────►  │   Metric     │  ──► Alert
   (e.g. severity=ERROR)│  Metric     │         │   in CM      │
                        └─────────────┘         └──────────────┘

   Useful when the underlying SDK/agent doesn't emit a metric directly.
```

## 3. Cloud Logging Architecture

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │                           LOG ROUTER                                 │
  └────────────────────────────────┬─────────────────────────────────────┘
                                   │ filter + route
       ┌───────────────┬───────────┴──────────┬─────────────────┐
       ▼               ▼                      ▼                 ▼
  ┌──────────┐  ┌──────────────┐       ┌─────────────┐  ┌──────────────┐
  │ Log      │  │  BigQuery    │       │   Cloud     │  │  Pub/Sub     │
  │ bucket   │  │  dataset     │       │   Storage   │  │   topic      │
  └──────────┘  │  (analytics) │       │  (archive)  │  │  (SIEM)      │
                └──────────────┘       └─────────────┘  └──────────────┘
```

### Log Buckets

```
                            ┌── _Required
                            │     Admin Activity audit logs
                            │     CANNOT be disabled
                            │     Default 400-day retention
                            │
        Log Buckets ────────┤── _Default
                            │     Everything else
                            │     Can disable
                            │     Default 30-day retention
                            │
                            └── Custom buckets
                                  - 1 day to 10 years retention
                                  - Optional Log Analytics upgrade
```

### Sinks (Routing Logs Out)

```
                            ┌── Log bucket
                            │
                            ├── BigQuery dataset
                            │     SQL on logs
   Sink destinations ───────┤
                            ├── Cloud Storage bucket
                            │     cheap archive
                            │
                            ├── Pub/Sub topic
                            │     stream to SIEM (Splunk, Chronicle...)
                            │
                            └── Another project (logs aggregation)


   IMPORTANT: After creating a sink, GRANT the sink's writer SA
              permission on the destination (e.g. BigQuery Data Editor).
```

## 4. Audit Logs

```
  ┌──────────────────────────┬───────────────────────┬───────────────────┐
  │  Type                    │  What it records      │  Default          │
  ├──────────────────────────┼───────────────────────┼───────────────────┤
  │  Admin Activity          │  config / IAM changes │  ALWAYS ON        │
  │  System Event            │  Google-side actions  │  ALWAYS ON        │
  │  Policy Denied           │  blocked by org policy│  ALWAYS ON        │
  │  Data Access             │  who read/wrote data  │  OFF (most svc)   │
  │                          │                       │  - opt in per svc │
  └──────────────────────────┴───────────────────────┴───────────────────┘

  EXAM TRAP: "Who read this BQ table?" ──► Data Access logs (must enable)
```
