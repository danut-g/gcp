```
                                            │
                            ┌───────────────┼───────────────┐
                            ▼               ▼               ▼
                     ┌────────────┐  ┌────────────┐  ┌────────────┐
                     │  Folder:   │  │  Folder:   │  │  Folder:   │
                     │   prod     │  │  nonprod   │  │  shared    │
                     └─────┬──────┘  └─────┬──────┘  └─────┬──────┘
                           │               │               │
                      ┌────┴────┐     ┌────┴────┐     ┌────┴────┐
                      ▼         ▼     ▼         ▼     ▼         ▼
                 ┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐

                      │
              ┌───────┼───────┐

            [VM]   [Bucket] [BQ]    ← Resources (live in exactly one project)
```

### Hierarchy Rules

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │  HIERARCHY RULES                                                     │
  ├──────────────────────────────────────────────────────────────────────┤
  │  1. Organization ─── optional but recommended                        │
  │     (Cloud Identity Free gives you a "standalone organization")      │
  │  2. Folders ──────── optional, can nest up to 10 levels deep         │
  │  3. Projects ─────── MANDATORY (every resource needs one)            │
  │  4. Resources ────── always belong to exactly ONE project            │
  └──────────────────────────────────────────────────────────────────────┘
```

### Project Identifiers

```
  ┌───────────────┬──────────────────┬──────────────┬─────────────────────┐
  │  Identifier   │  Mutable?        │  Unique?     │  Example            │
```

## 2. Inheritance: IAM vs Organization Policy

```
  ┌──────────────────────────────────┬──────────────────────────────────┐
  │              IAM                 │       ORGANIZATION POLICY        │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  Controls WHO can do things      │  Controls WHAT can be done       │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  Grants roles to members         │  Sets constraints on resources   │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  "Alice can create VMs"          │  "No VM may have external IP"    │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  Combination: UNION              │  Combination: INTERSECTION       │
  │  Most permissive wins            │  Most restrictive wins           │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  Child cannot REMOVE parent's    │  Child cannot LOOSEN parent's    │
  │  grant                           │  constraint (unless allowed)     │
  └──────────────────────────────────┴──────────────────────────────────┘

  EXAM RULE OF THUMB:   IAM = additive       Org Policy = restrictive
```

### IAM Inheritance Example

```
           ┌──────────────────────────────────────┐
           │          ORGANIZATION                 │
           │  Editor for group:ops@co.com          │
           └──────────────────┬───────────────────┘
                              │ inherits down
           ┌──────────────────▼───────────────────┐
           │           FOLDER: prod                │
           │  Viewer for user:alice@co.com         │
           └──────────────────┬───────────────────┘
                              │
           ┌──────────────────▼───────────────────┐
           │           PROJECT: web-app            │
           │  Effective:                           │
           │    alice = Viewer (from folder)       │
           │    ops   = Editor (from org)          │
           └──────────────────────────────────────┘
```

## 5. Quotas

```
                          ┌── Rate Quotas
                          │     - Reset over time
                          │     - e.g. API calls/100 sec
                          │
        Quotas ───────────┤
        (per-project,     │
         per-region)      └── Allocation Quotas
                                - Total resources
                                - e.g. CPUs in us-central1


  QUOTA INCREASE PROCESS
  ──────────────────────
  1. IAM & Admin ──► Quotas
  2. Filter by service / metric / location
  3. Select quota ──► Edit Quotas
  4. Enter new limit + justification
  5. Submit ──► Google Support reviews (NOT instantaneous, 24-48h)

  EXAM TIP: Quota error = HTTP 429
  EXAM TIP: "Need more capacity tomorrow" = REQUEST INCREASE NOW
  EXAM TIP: If you constantly hit quota, redesign (split projects, etc.)
```

## 6. Geographic Availability

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │                        GLOBAL INFRASTRUCTURE LAYERS                  │
  └──────────────────────────────────────────────────────────────────────┘

      Continent (multi-region: us / eu / asia)
        │
        └── Region (40+ regions e.g. europe-west3 = Frankfurt)
              │   - Isolated for fault containment
              │   - Pick for: latency, residency, availability, price
              │
              └── Zone (3+ per region e.g. -a -b -c)
                    │   - Independent failure domain
                    │   - Power, cooling, networking
                    │   - <1ms RTT to other zones in same region
                    │
                    └── Resources (VMs, PDs, GKE nodes)

       ─── all connected by ───
       Google's private global backbone
       ─── reaches users via ───
       180+ Edge PoPs (Cloud CDN, global LB, Cloud Armor)
```

### Service Scope

```
  ┌────────────────┬───────────────────────┬──────────────────────────┐
  │     Scope      │     Lives in          │     Examples             │
  ├────────────────┼───────────────────────┼──────────────────────────┤
  │  GLOBAL        │ outside any region    │ IAM, Cloud DNS, global LB│
  │  REGIONAL      │ one region, multi-AZ  │ regional PD, regional MIG│
  │  ZONAL         │ a single zone         │ default GCE VM, zonal PD │
  │  MULTI-REGION  │ continent (us/eu/...) │ GCS multi-region, BQ     │
  └────────────────┴───────────────────────┴──────────────────────────┘

  HA / DR RULE
  ─────────────
  HA:  >= 2 zones inside a region
  DR:  >= 2 regions across a continent
```

### Edge / Premium Tier

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │  PREMIUM NETWORK TIER  =  user enters at nearest Edge PoP            │
  │                          + traffic stays on Google backbone          │
  │                          + Cloud CDN cache at edge                   │
  │                          + Cloud Armor DDoS/WAF inspection at edge   │
  │                                                                      │
  │  STANDARD TIER         =  traffic uses public internet               │
  │                          + cheaper, regional only                    │
  └──────────────────────────────────────────────────────────────────────┘
```

## 9. Section 1.1 Cheat Sheet

```
  ┌──────────────────────────────────────────────────────────────────────────────┐
  │  1.1 QUICK REFERENCE                                                         │
  ├──────────────────────────────────────────────────────────────────────────────┤
  │  HIERARCHY      Org ──► Folders (optional) ──► Projects (required) ──► Res.  │
  │  PROJECT ID     IMMUTABLE, globally unique, ~30d undelete window             │
  │  IAM            Inherits down, UNION (most permissive wins)                  │
  │  ORG POLICY     Inherits down, INTERSECTION (most restrictive wins)          │
  │  CLOUD IDENTITY admin.google.com (NOT the same as IAM)                       │
  │  GROUPS         Always grant roles to GROUPS, not users                      │
  │  APIs           Per-project enable; SERVICE_DISABLED is the tell             │
  │  QUOTAS         Rate + Allocation; increases via support (NOT instant)       │
  │  REGIONS        Pick for latency, residency, availability, price             │
  │  HA RULE        2 zones in a region; 2 regions for DR                        │
  │  PREMIUM TIER   Backbone + edge PoPs (global LB, CDN, Armor)                 │
  │  ASSET INVENTORY  35-day history, search/export, Pub/Sub feeds               │
  │  STANDALONE ORG Cloud Identity Free tenant (no Workspace)                    │
  └──────────────────────────────────────────────────────────────────────────────┘
```
