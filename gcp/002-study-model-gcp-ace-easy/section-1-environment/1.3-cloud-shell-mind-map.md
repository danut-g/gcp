## 3. Anatomy of a gcloud Command

```
   gcloud   compute     instances    create     my-vm    --zone=europe-west1-b
   ──────   ─────────   ──────────   ────────   ──────   ─────────────────────
   tool     PRODUCT     RESOURCE     VERB       NAME     FLAGS

   ┌──────────────┬────────────────────────────────────────────┐

   │  --format    │  json / yaml / table / value               │
   │  --filter    │  show only matching rows                   │
   └──────────────┴────────────────────────────────────────────┘
```

## 4. Setup Commands: Who Does What

```
  ┌─────────────────────────────────────────────────────────────────────┐
  │  gcloud init  =  WIZARD                                             │
  │     ├── gcloud auth login            (authenticate: human, browser) │
  │     ├── gcloud config set project    (default project)              │
  │     └── gcloud config set compute/…  (default region/zone)          │
  └─────────────────────────────────────────────────────────────────────┘

  AUTH: three credential flavours
  ┌──────────────────────────────────────┬──────────────┬────────────────┐
  │  Command                             │  Identity    │  Used by       │
  ├──────────────────────────────────────┼──────────────┼────────────────┤
  │  gcloud auth login                   │  human       │  gcloud CLI    │
  │  gcloud auth activate-service-account│  robot (key) │  CI / servers  │
  │  gcloud auth application-default     │  human → ADC │  YOUR CODE     │
  │         login                        │              │  (libraries)   │
  └──────────────────────────────────────┴──────────────┴────────────────┘

  EXAM RULE OF THUMB:  CLI works but script fails to auth  →  missing ADC
```

## 5. Configurations (Profiles)

```
                ┌─────────────────────────────────────┐
                │   gcloud config configurations ...  │
                └──────────────────┬──────────────────┘
                                   │
            ┌──────────────────────┼──────────────────────┐
            ▼                      ▼                      ▼
   ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
   │   default       │   │   work          │   │   personal      │
   │ acct: me@x.com  │   │ acct: me@co.com │   │ acct: me@gmail  │
   │ proj: sandbox   │   │ proj: co-prod   │   │ proj: hobby     │
   │ zone: us-c1-a   │   │ zone: eu-w1-b   │   │ zone: eu-w3-c   │
   └─────────────────┘   └────────┬────────┘   └─────────────────┘
                                  │
                          ACTIVATE one at a time:
                          gcloud config configurations activate work

   One-off override (no switching):   any command + --project=hobby

   TRIGGER PHRASE on the exam:
   "manages multiple projects/accounts from one machine,
    keeps using the wrong one"  →  CONFIGURATIONS
```

## 6. Components (laptop SDK only)

```
   CORE INSTALL                     ADD-ON COMPONENTS
   ┌──────────┐    install     ┌────────────────────────────┐
   │  gcloud  │ ─────────────► │ kubectl │ beta │ alpha │…  │
   └──────────┘                └────────────────────────────┘

   gcloud components list / install NAME / update

   "Invalid choice: 'beta'"  →  gcloud components install beta
                                 (NOT an IAM problem)

   ⚠ Cloud Shell: components are pre-installed & Google-managed
     → you don't run `components install` there
```

## 7. Cloud Shell

```
   Browser ──click >_ icon──►  ┌────────────────────────────────────┐
                               │       CLOUD SHELL VM (free)        │
                               │  pre-installed: gcloud, kubectl,   │
                               │  bq, git, terraform, editors…      │
                               │  pre-authenticated as YOU          │

   ┌────────────────────────┬───────────────────────────────────────┐
   │  Cost                  │  free                                 │
   │  Persistent storage    │  5 GB at $HOME only                   │
   │  Idle timeout          │  ~20 min                              │

   USE IT WHEN…                        DON'T USE IT WHEN…

   ✓ borrowed/any machine              ✗ scheduled/unattended work
   ✓ quick one-off admin               ✗ heavy builds / big transfers
```

## 8. Decision Mini-Tree

```
  "Run a gcloud command, no install allowed?" ──────────► CLOUD SHELL
  "Wrong-project accidents, multi-client laptop?" ─────► CONFIGURATIONS
  "Script/library can't authenticate locally?" ────────► auth application-default login
  "CI server has no active account?" ──────────────────► activate-service-account (key)
  "Invalid choice: beta?" ─────────────────────────────► components install beta
  "API not enabled error?" ────────────────────────────► gcloud services enable …
  "kubectl can't see the cluster?" ────────────────────► container clusters get-credentials
```
