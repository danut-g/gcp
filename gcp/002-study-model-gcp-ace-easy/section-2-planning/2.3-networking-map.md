## 2. Sharing & Connecting VPCs

```
                                 ┌── Same VPC
                                 │     - Free, full visibility
                                 │
                                 ├── SHARED VPC
                                 │     - Host project owns network
   Cross-Project / VPC ──────────┤     - Service projects use it
                                 │     - CENTRALISED admin
                                 │
                                 ├── VPC PEERING
                                 │     - Private RFC1918 connectivity
                                 │     - NON-TRANSITIVE (A↔B, B↔C ≠ A↔C)
                                 │     - Both sides must peer
                                 │
                                 └── PRIVATE SERVICE CONNECT
                                       - Producer/consumer model
                                       - Reach managed services
```

## 4. Cloud NGFW (Firewall) Rules

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │  FIREWALL RULE COMPONENTS                                            │
  ├──────────────────────────────────────────────────────────────────────┤
  │  Direction      ─── ingress / egress                                 │
  │  Action         ─── allow / deny                                     │
  │  Priority       ─── 0..65535 (lower wins)                            │
  │  Targets        ─── all instances / network tag / service account /  │
  │                     SECURE TAG (IAM-controlled)                      │
  │  Sources        ─── IP ranges / network tags / service accounts      │
  │  Protocols/Ports                                                     │
  └──────────────────────────────────────────────────────────────────────┘
```

### Defaults

```
                        ┌── INGRESS implicit DENY (everything blocked)
        Default rules ──┤
                        └── EGRESS  implicit ALLOW (everything out)

  Default VPC adds these starter rules:
    default-allow-internal     (within the VPC)
    default-allow-ssh          (port 22)
    default-allow-rdp          (port 3389)
    default-allow-icmp
```

### Tags vs Secure Tags vs Service Accounts

```
  ┌──────────────────────┬────────────────────────────────────────────┐
  │  Network Tags        │  Free strings on a VM, no IAM control      │
  │                      │  Anyone with editor can add them           │
  ├──────────────────────┼────────────────────────────────────────────┤
  │  Secure Tags         │  IAM-controlled labels (newer)             │
  │                      │  Cannot be set without permission          │
  ├──────────────────────┼────────────────────────────────────────────┤
  │  Service Accounts    │  STRONGEST identity-based target           │
  │  (RECOMMENDED)       │  Tied to the workload's identity           │
  └──────────────────────┴────────────────────────────────────────────┘

  EXAM TIP: For identity-based firewalls, prefer SAs > secure tags > network tags.
```

## 5. Load Balancer Family

```
  ┌──────────────────────────────────────────────────────────────────────┐
  │                          LAYER 7 (Application LB)                    │
  ├──────────────────────────────────────────────────────────────────────┤
  │   Global external Application LB    ◄─── public, multi-region        │
  │   Regional external Application LB  ◄─── public, single region       │
  │   Internal Application LB           ◄─── internal-only               │
  │   Cross-region internal Application LB                               │
  └──────────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │                          LAYER 4 (Network LB)                        │
  ├──────────────────────────────────────────────────────────────────────┤
  │   External proxy Network LB         ◄─── TCP/SSL proxy               │
  │   External passthrough Network LB   ◄─── L4 passthrough              │
  │   Internal passthrough Network LB   ◄─── L4 internal                 │
  └──────────────────────────────────────────────────────────────────────┘
```

### LB Decision Quick Picks

```
  ┌──────────────────────────────────────┬──────────────────────────────┐
```

## 6. Network Service Tiers

```
  ┌──────────────────────────────────┬──────────────────────────────────┐
  │  PREMIUM  (default for global LB)│  STANDARD                        │
  ├──────────────────────────────────┼──────────────────────────────────┤
  │  Traffic on Google's BACKBONE    │  Traffic on the public internet  │
  │  Enters at nearest Edge PoP      │  Regional only                   │
  │  Lower latency, higher SLA       │  Cheaper                         │
  │  Required for global LB / CDN    │                                  │
  └──────────────────────────────────┴──────────────────────────────────┘
```

## 7. Cloud DNS & Cloud NAT (briefly)

```
                            ┌── Public managed zones    (internet-facing)
                            ├── Private zones           (per VPC)
        Cloud DNS ──────────┤── Forwarding zones        (resolve via on-prem)
                            └── Peering zones           (across VPCs)


                            ┌── Outbound for VMs without external IPs
        Cloud NAT ──────────┤── No INBOUND (NAT is one-way)
                            └── Per region; Cloud Router required
```

```
  ┌──────────────────────────────────────────────────────────────────────────────┐
  │  2.3 QUICK REFERENCE                                                         │
  ├──────────────────────────────────────────────────────────────────────────────┤
  │  VPC            Global resource; subnets are regional                        │
  │  MODES          Auto = labs; CUSTOM = production                             │

  │  INTERCONNECT   Dedicated 10/100G or Partner via service provider            │
  │  FIREWALL       Implicit deny ingress, allow egress                          │
  │  TARGETS        SAs > secure tags > network tags (least to most secure)      │
  │  LB L7          Global / Regional / Internal Application LB                  │
  │  LB L4          Proxy or Passthrough; external or internal                   │
  │  NETWORK TIER   Premium = backbone + edge; Standard = public internet        │
  │  CLOUD DNS      Public + private + forwarding + peering zones                │
  │  CLOUD NAT      Outbound only for private VMs                                │
  │  PGA            Private Google Access for VMs without external IPs           │
  │  GLOBAL LB      Requires Premium tier                                        │
  └──────────────────────────────────────────────────────────────────────────────┘
```
