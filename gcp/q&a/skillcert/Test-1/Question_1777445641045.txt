30. Question
You are running an application on multiple virtual machines within a managed instance group and have auto-scaling enabled. The autoscaling policy is configured so that additional instances are added to the group if the CPU utilization of instances goes above 80%. VMs are added until the instance group reaches its maximum limit of five VMs or until CPU utilization of instances lowers to 80%. The initial delay for HTTP health checks against the instances is set to 30 seconds. The virtual machine instances take around three minutes to become available for users. You observe that when the instance group auto-scales, it adds more instances then necessary to support the levels of end-user traffic. You want to properly maintain instance group sizes when autoscaling. What should you do?

  Decrease the maximum number of instances to 3.
  Increase the initial delay of the HTTP health check to 200 seconds.
  Set the maximum number of instances to 1.
  Use a TCP health check instead of an HTTP health check.
