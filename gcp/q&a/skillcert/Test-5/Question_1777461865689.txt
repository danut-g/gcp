45. Question

Currently Project wide access has already been granted to all the instances within the projects.   C. Use the gcloud compute project-info add-metadata [INSTANCE_NAME] --metadata block-project-ssh-keys=FALSE command to block the access.
  D. Project wide SSH access cannot be overridden or blocked and needs to be removed.
